This is my mmap-based implementation of **malloc** for CS 4400, Computer Systems, at the University of Utah.

In this assignment, I was also asked to implement **free** and **init.**

My malloc implementation uses an explicit free list, splitting, coalescing, smart chunking, and the unmapping of unused heap pages. 

See **malloclab-handout/mm.c** for my implementation
